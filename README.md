# Hotel Operations System / Hospitality IT Solution

A practical web-based solution designed to manage daily hotel and resort operations efficiently.

This system focuses on real-world usability — helping hospitality managers handle bookings, track finances, monitor availability, and maintain operational clarity from a single platform.

---

## Core Functionalities

### Booking Management

* Add bookings through structured form or quick raw-text input
* Edit and update reservations
* Search bookings by guest, contact, date, or resort
* Automatic calculation of nights, balance, and guest count

---

### Financial Management (P&L)

* Monthly revenue tracking
* Expense management with category classification
* Automated profit and balance calculations
* Export professional Excel reports for accounting purposes

---

### Multi-Property Support

* Manage multiple hotels or resorts within one system
* Track total room inventory per property
* Filter data based on selected property

---

### Availability Tracking

* Monthly availability calendar
* Daily booked vs available room tracking
* Helps in operational planning and pricing decisions

---

### Role-Based Access

* Admin access for full control
* Staff access for operational usage

---

## Technology Stack

* Backend: Python (Flask)
* Database: SQLite
* Frontend: HTML (Jinja Templates)
* Excel Reports: OpenPyXL

---
